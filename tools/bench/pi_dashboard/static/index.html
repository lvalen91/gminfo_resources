613/614 VIP dev-interface test (Tier 1, live, non-destructive)

      
Connects the CAN 613/614 VIP development interface and saves + verify-reads the two
      verifier words (FEBF0BF8 / FEBF0BFC) to confirm the link is live without touching
      calibration data. A genuine/stock calibration write does not use 613/614 at all.

      
      

    

    

      ⚠ Danger zone — live calibration write (Tier 2, destructive)
      

        
Writes calibration modules to the real ECU over CAN. The action runs the
        613/614 VIP link pre-flight check, then one UDS programming session, then an F182 verify.

        

          
Upload a full package .zip of part-number-named
          modules, or one or more individual module files (each named by its GM part number). The
          slots present in the upload are detected below. A module whose bytes match the stock
          reference writes genuine; a modified module writes through the 613/614 override path.

          
          
          

            
            
          

        

        

        

      

    

  


  
  

    
ELK

    

      
ELK status (recovery bootloader)

      
ELK is the Intel kernelflinger fastboot-class bootloader (USB 8087:09EF,
      iface FF/42/03). A RAM image boot is volatile / non-persistent (no flash, cannot burn a fuse). Flash/SPI
      writes are intentionally not exposed here. The CAN F000/8180 entry trigger is a candidate (bench-confirmed
      entry route is MEI/HECI).

Field capture raw T1 + CAN + UART to a USB drive

    
Total, unfiltered capture for in-vehicle sessions: every Ethernet frame on the physical
    eth0 (all VLANs and untagged), every can0 frame
    (plus error frames, with RX/TX marked) and the raw VIP console byte stream. It runs alongside
    everything else — the CAN observer, decoder, keepalive, UDS and the live UART view are not
    touched. Files go only to an external USB drive, one timestamped folder per session.
    Stop closes every file, syncs and unmounts the drive.
